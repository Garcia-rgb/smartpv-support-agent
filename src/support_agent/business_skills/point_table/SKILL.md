# 点表制作

版本：1.0.0

## 触发

用户明确要求制作、生成、导出南向/北向点表，或上传设备协议进行制作。

## 执行流程

1. 确认南向/北向、厂家型号和协议版本。使用已有点表编辑器接收设备协议 Word/PDF。
2. 调用已有 `/point-tables/parse` 提取原文明确列出的点位，保留地址、数据类型、单位、倍率和读写属性。未提供的项留空，要求用户填写。
3. 用户核对点位并补充公共字段，调用 `/point-tables/validate`。错误阻止生成，警告需人工确认。
4. 用户确认后调用 `/point-tables/generate` 下载文件。不能声称生成文件已上传数采或现场生效。

## 约束

- 不凭模型记忆编造寄存器地址、型号专用协议或控制点。
- 北向点号不能直接照抄南向 Modbus 寄存器地址。
- 资料编号40001、协议偏移0、项目点表地址是不同表达，必须核对地址基数。
- 多寄存器字序、位定义及增益的乘除含义必须依据厂家协议/项目规则确认。
- 缺协议或缺参数时先补充，不输出看似完整的虚构点表。

## 输出

简短说明当前步骤和缺失项，并打开现有上传解析编辑流程。真实生成和下载由程序执行。
