# 点表制作

## 固定输出格式

沿用此前成功导入的模板：南向24列、北向4列。输入文件中的表头用于寻找数据，不直接替换导出模板。Excel核对版包含“导入点表”和“制作说明”，CSV用于软件导入。

日常界面只需选择南向/北向并上传一份数据文件，不选择来源类型或协议，不另行上传模板。协议从文件内容识别；一份包含逐行设备与协议字段的南向数据文件可含Modbus和104。底层多文件合并接口保留兼容，界面不再要求用户同时选择不同协议的文件。

支持本机解析 XLSX、XLSM、CSV、Word（DOC/DOCX）和文字版PDF。旧版XLS须另存为XLSX。不会执行Excel宏或公式，也不会把整份来源发送给外部模型。公式值须先粘贴为值再上传。

## Excel来源

- 自动读取设备表和信息点表多个工作表，按列名匹配固定模板字段。
- Modbus设备共用一套点位时，按设备逐台展开；每台设备的通道、业务编号和从站地址分别保留。
- 104是另一种南向协议，按业务编号关联设备与点位，不要求填写Modbus从站地址、寄存器类型或读写类型。当前固定模板的104数据类型为FLOAT。
- 界面上传一份文件；底层保留多文件合并能力用于兼容：每份文件先按自身协议关联设备和展开点位，再合并到一份固定24列CSV，统一生成不重复流水号。单份带设备表的来源仍需明确协议；不把104点位复制到Modbus设备或反向分配。业务编号重复、点位找不到对应设备或必要字段缺失时，提示核对并阻止导入CSV。
- 增益直接保留原值，不自动取倒数；偏移量、持久化、BIT位和单位分别保留。列名“电站名称”对应固定输出的“电站编号”。
- 字典依据为本地资料库 `点表规则/DictModel.csv`。仅在设备类型/实例、DEV层级、归一化名称和信号类型均明确对应、状态有效且不是计算点时填入编码；没有明确映射或多义时留空，不回填中文名称，不从旧说明书映射猜测。文件内容仅保存在被Git忽略的本机资料目录。

## 界面与检查

上传后可以修改设备信息和点位字段。检查地址重复时区分设备、寄存器类型、读写方向及BIT位；104不套用Modbus寄存器宽度规则。北向地址需要明确填写，不把来源中的南向协议地址自动当作北向点号。

含多种协议的数据逐行显示通道、设备与协议，可继续核对修改；104不适用的Modbus字段禁用。已经导出的、带完整设备字段的合并CSV也可重新上传，无需再拆成不同协议。CSV重新读取使用文件核对模块的2000行上限，超过时请拆分。

检查通过后可下载CSV和Excel。检查未通过也可下载标为“待确认”的Excel核对版，其中冲突或缺失值留空并在说明页列明；CSV仍被阻止。

单份原始点表最多500个点位、200台设备；设备展开后最多20000条记录。格式检查和字段核对不等于已在现场完成软件导入或设备对点，导入前仍需确认地址基数、字序、单位、增益和控制点。

## 人工成品对照后固定的规则

已确认并加入回归检查：固定24列及顺序、设备字段按来源列映射、Modbus共用点位按设备展开、104按业务编号关联、地址与数据类型保留、单位与持久化保留、明确的归一化映射保留、104不填写Modbus设备地址/寄存器类型/读写类型。测试使用虚构设备和字典数据，不包含客户资料。

用户确认的最终交付格式是一份包含多种协议的南向CSV，各行保留自己的协议及设备归属。界面上传一份数据文件；不能把跨协议共表误解为可以把不同协议的点位交叉分配给设备。

人工对照结果与参数适用边界：

- 信号点ID：用户确认不重复流水号可用；合并后统一编号，不按文件重新从1编号。
- 104增益与偏移量：原始Excel的数值与人工成品不同；现实现复制原值。用户确认增益需要与实际数值比较，不是可从本次成品推导的固定规则。来源增益只代表文件提供的参数，不代表已完成现场校准。校准时需对齐设备、点位、时间及单位，并确认平台使用的倍率计算方式；校准结果适用于对应设备和点位，不能自动推广到其他设备、型号或站点。说明书要求参考三方通管机，也不能把全部104遥信强制设为同一偏移量。
- 字典缺项：用户确认没有固定对应关系时留空；以提供的DictModel.csv明确匹配，不照抄人工成品的中文占位值。
- 104采集周期：用户确认留空，CSV和Excel核对版均不再套用Modbus默认周期。
- 104遥信偏移量：用户确认本次来源的0正确，人工成品的-1错误；保留来源值，不建立自动减1的规则。
- 人工成品设备型号与业务编号不一致处，用户确认按原始设备表关联。
