# 工程工具与业务 Skill

版本：v1.13.0

## 使用

直接聊天或点击输入区的具体工具入口，结果与其他对话一起保存。

| 能力 | 示例 | 执行方式 |
|---|---|---|
| 报文解析 | `解析Modbus RTU请求报文：01 03 00 00 00 02 C4 0B` | 本机程序校验及解析 |
| 寄存器解码 | `寄存器解码：[0x43C8,0x0000]，FLOAT32，ABCD，乘数0.1` | 本机程序计算，结果为40 |
| 解码追问 | 在上例同一对话继续问 `换成CDAB呢` | 沿用原值与类型，切换明确指定字序 |
| 点表制作 | `帮我制作北向点表` | 返回上传入口，调用已有解析、补缺、校验与生成流程 |
| 现场排查 | 描述故障，再反馈 `检查了采集器供电正常，重启无效，下一步呢` | 当前问题状态 + 资料检索 + 业务规范指导模型回答 |

## 报文工具边界

- 支持单帧RTU/TCP及常用01、02、03、04、05、06、0F、10功能码与异常响应。其他功能码保留原始字段并明确未展开校验。
- RTU检查CRC、设备地址及功能数据长度；TCP检查MBAP协议标识与长度。没有实际连接设备，也不发送任何写指令。
- 05/06请求与正常回显格式相同，不能根据单帧证明写入已执行；自动判别有歧义时应指定方向。
- 协议偏移地址与40001等文档编号分开解释；报文缺失、CRC错误、异常码均不能单独证明设备硬件故障。

## 寄存器工具边界

- 支持有符号/无符号16、32、64位整数及32、64位IEEE浮点；原始寄存器值必须在0至65535范围。
- 字节序是寄存器内两个字节的顺序，字序是多个寄存器的顺序。32位支持ABCD/BADC/CDAB/DCBA；64位支持整体高字/低字在前，不支持任意厂家自定义排列。
- 字序未确认时列出候选值，不自动选择；NaN/Infinity不会作为有效测量值。
- 换算采用 `原值 × 乘数 + 偏移`。只说“倍率/增益”且没有乘除含义时要求确认；不把项目点表的除数增益直接当乘数。

## Skill 的实际加载

仅加载项目内白名单中的两份 `business_skills/*/SKILL.md`，版本各为1.0.0。上传协议和知识库文档不作为可执行Skill，不接受任意路径或脚本。

- 点表 Skill：识别明确制作意图，打开现有认证保护的编辑器，支持北向预选。缺原文地址不编造，校验错误不能导出，最终仍须人工核对。
- 现场 Skill：规范加入实际问答模型的系统提示；连续追问带上用户描述和实际检查反馈，将旧助手建议标为参考。长对话保留当前问题起点，明确“新问题/换个问题”后切换上下文。
- 工具执行与Skill激活写入现有本机审计日志；报文和寄存器工具本机运行，不调用远程生成模型。现场资料问答继续遵循现有DeepSeek配置和资料分库策略。

学习答题 Skill 和聊天调用文件核对能力本轮未新增，已有学习及文件核对功能保持当前实现。

## 验证

离线测试覆盖公开RTU请求CRC向量、TCP长度、异常码、写回显歧义、数量限制、四种字序、符号位、非有限浮点、倍率含义、聊天调用、同会话追问与账号隔离。前端检查覆盖参数表单、统一聊天提交、注销清理和北向点表入口。

协议参考：[Modbus Application Protocol V1.1b3](https://www.modbus.org/file/secure/modbusprotocolspecification.pdf)。跨寄存器组合、设备寄存器表和专用参数仍以厂家协议为准。
