# 普通资料与隐私资料分流（v1.5.0）

## 当前规则

- 新导入片段默认标记为 `private`。未标记的旧片段也按隐私资料处理。
- 只有人工选定来源且通过敏感词复核的片段标记为 `public`。本机这次把华为产品手册、HCSA 课程和模拟题中的 1646 个片段列入普通资料；另有 53 个包含账号、客户等线索的片段留在隐私库。重新导入资料后须重新分类。
- 问题含客户、工单、现场、地址、账号等线索，或公开资料检索分数不足时，按隐私问题处理。未知问题默认隐私。普通问答发给 DeepSeek 的只有当前问题和普通资料片段，不附带聊天历史。
- 隐私问答使用本地检索和本地生成模型。缺少本地生成模型时只能返回本地摘要；资料不足时不让 DeepSeek 接手原问题。
- 隐私问题本地检索不足时，公开网页搜索仅接收由白名单产品型号和通用故障词重新组成的短查询，不接收原问题、会话历史或内部资料片段。搜索结果也只送本地模型整理。

## 启用与检查

在本机 `.env` 设置：

```dotenv
PRIVACY_ROUTING_ENABLED=true
ALLOW_REMOTE_LLM=true
LOCAL_LLM_BASE_URL=http://127.0.0.1:11434/v1
LOCAL_LLM_MODEL=qwen3-local:1.7b
# 可选：需要申请公开搜索接口的密钥；留空时无依据则直接提示无法确定
PUBLIC_SEARCH_API_KEY=
```

`ALLOW_REMOTE_LLM` 仅允许普通问题使用远程模型。`LOCAL_LLM_BASE_URL` 必须是本机回环 HTTP 地址；仅填模型名但本地服务未启动时，私有问答会降级为检索摘要。`/health` 可查看隐私分流与本地模型配置是否启用，但配置启用不代表模型进程已启动。

分类脚本默认预览：

```powershell
python scripts/classify_public_knowledge.py
python scripts/classify_public_knowledge.py --apply
```

执行 `--apply` 前应人工核对公开来源与课程内容。修改资料或新增课程后，应再次复核。脚本只认识列明的文件名和课程命名规则，不会把任意导入文件自动公开。

## 尚未完成的验收

- 本地轻量模型需在目标机器上完成实机问答和断网测试。模型在普通电脑上的回答质量可能低于 DeepSeek。
- 公开网页搜索需配置服务密钥，并验证清洗后的查询、结果引用与失败降级。
- 自动分类仅用于缩小外发范围，不能代替企业对资料公开属性的人工审核。上线前应针对真实工单、设备序列号、联系方式和内部术语做专项回归。
