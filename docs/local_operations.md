# 本机运行、备份与验收

## Windows 离线安装

解压 `SmartPVSupport-1.15.0-windows.zip`，双击 `Install.cmd`。程序安装到 `%LOCALAPPDATA%\SmartPVSupport\releases\版本号`，用户数据固定保存在同目录的 `data` 文件夹。首次安装会在安装窗口显示一次管理员初始密码，登录后修改。桌面启动项为“光伏技术支持客户端”。需 Windows 10/11、.NET Framework 4.8 与 Microsoft Edge WebView2 Runtime；无需另装 Python。

安装包仅包含程序、Python 与依赖库，不包含现有项目的数据库、公司资料、聊天记录或 `.env`。新装默认关闭远程模型；管理员需在 `data\.env` 配置模型与资料路径。现有项目的配置不改变。默认使用 Hash 检索；需要语义检索时配置本地 ONNX 模型目录。

## 升级与回退

先关闭客户端，再解压新版安装包并运行 `Install.cmd`。升级会先备份数据，对新包逐文件校验并执行运行探测，成功后才切换启动版本。账号、对话、资料与配置不随程序覆盖。

运行安装目录的 `Rollback.cmd` 切回前一程序版本。当前数据库变更为新增表，兼容回退；未来若有破坏性数据库迁移，需专门设计迁移和恢复，不能直接沿用此机制。校验和用于发现损坏，不是发布者数字签名；当前为本地 ZIP 安装包，尚无签名安装器或自动下载更新。

## 稳定性范围

统一发送接口使用请求 ID 持久化去重。同一请求成功后重试返回已保存结果；执行结果不确定时停止重做，先查看历史再决定是否新发。同会话并发限制用于单服务进程。默认处理超时 120 秒，配置 `INPUT_TIMEOUT_SECONDS` 可调整。桌面只管理自己启动的服务，异常退出最多重启三次；无法恢复时检查 `data\.logs\desktop.log`。

## 备份与恢复

服务启动后后台检查备份时间，默认每 24 小时备份 SQLite 数据库和 `knowledge_base` 原件，保留七份自动备份，手动备份不自动删除。参数：`AUTOMATIC_BACKUP_ENABLED`、`AUTOMATIC_BACKUP_INTERVAL_HOURS`、`AUTOMATIC_BACKUP_KEEP`。数据库内的账号、对话、图片、资料片段一并备份。`.env` 和远程密钥不进入备份，需独立安全保管。

管理中心“备份与恢复”显示最近自动备份状态，可创建、下载备份及运行“恢复校验”。校验在 `.backups\restore-checks` 新目录验证哈希、数据库完整性和数据条数，不覆盖当前数据库。恢复副本清除登录会话，恢复后重新登录。定期把备份复制到另一块磁盘；当前电脑整盘损坏时，仅本机备份无法保障恢复。

## 回答验收

`python scripts/run_acceptance.py` 默认使用隔离测试库和 12 个合成问题，不调用远程模型。覆盖平台缺数据排查、Modbus/寄存器工具、字序追问、点表流程、无依据题目拒答、上下文及注入拦截。报告写入被 Git 忽略的 `本地文档\验收报告\latest.json`。

正式业务验收需增加实际问题、正确处理方法、应引用资料、禁止误判项和人工审核结果。使用 `--suite 文件路径 --live-library` 对现有资料库做离线验证；只有显式添加 `--remote --allow-external-data` 才开启远程对照，执行人必须获得公司授权。规则通过不能证明现场根因正确，也不能代替工程人员审核。每次升级运行同一组问题，对比通过率、资料命中、耗时与人工评分。

## 包构建

`python scripts/build_desktop_package.py --output dist/SmartPVSupport-1.15.0-windows.zip`。只复制明确列出的程序、运行时和依赖目录。禁止把实际资料或密钥加入安装包。
